# 보관 자료

| 위치 | 내용 |
|---|---|
| [tts/RESTORE.md](tts/RESTORE.md) | 본체에서 분리한 TTS 코드와 향후 복원 절차 |
| [backups/README.md](backups/README.md) | 과거 변경 시점별 원본 백업 안내 |

기존 최상위 `backups/`는 `archive/backups/`로 이동했습니다. 이동 전후 전체 상대 파일 목록과 SHA-256을 비교하며, 보관 파일의 내용은 변경하지 않습니다. 과거 문서·소스에 남아 있는 `backups/`, 설치 파일, 모듈 이름과 실행 명령은 당시 배치를 나타냅니다.

백업의 manifest에 있는 파일 경로는 각 백업 폴더를 기준으로 해석합니다. 현재 프로젝트의 실행·설치는 [README](../README.md)를 따르세요. 이전 파일을 현재 본체에 복원할 때는 현재 변경 사항을 먼저 보존하고 필요한 코드와 의존성을 검토해야 합니다.

TTS 보관본은 현재 배치에서 실행을 보장하지 않는 참고 구현입니다. 모델·가상환경·녹음·프로필·캐시와 기존 로그는 프로젝트의 원래 위치에 유지합니다.
