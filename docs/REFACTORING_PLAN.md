# ROBOTPAL 파일 통합과 폴더 정리 기록

2026-10-21. 같은 기능을 더 적은 구현 파일로 관리하도록 활성 모듈을 17개에서 13개로 통합했습니다. 기존 실행법·기능과 선택적 화자 분리를 유지하고, TTS는 보관 상태로 둡니다.

## 소스 통합

| 이전 파일 | 현재 파일 | 책임 |
|---|---|---|
| live_transcription, utterance, transcription | `module/speech_pipeline.py` | 발화 상태·작업 자료형·임시/최종 전사 큐·모델 로딩·작업자 |
| api_common, conversation | `module/ai_api.py` | API 설정·오류·입력 구성·독립 대화 응답 |
| camera, vision_assistant | `module/vision_assistant.py` | 최신 카메라 프레임·JPEG·음성 명령 접수·FIFO·자원 관리 |

옛 내부 모듈은 삭제하고 import·테스트 mock 경로를 새 위치로 옮겼습니다. 호환 전달 파일은 추가하지 않았습니다. 직접 마이크 입력과 선택적 과거 음성 실행은 공유 파이프라인을 사용합니다. 음성 품질·평가, 행동 계획·분류 정책, 손 모양 실행·규칙, 로그는 각각의 경계를 유지합니다.

## 폴더 배치

- `main.py`, `ai_action_planner.py`, `README.md`, `requirements.txt`: 최상위 진입점과 기본 안내.
- `module/`, `tests/`: 활성 코드와 기존 동작별 테스트.
- `requirements/`: core, speech, vision, gesture, legacy-speech 설치 목록. 패키지와 버전 범위는 동일합니다.
- `docs/`: 음성 안내, 순서도, 정리 기록, 평가 예제 JSONL.
- `archive/tts/`: 기존 TTS 보관본을 바이트 변경 없이 유지.
- `archive/backups/`: 기존 backups 전체를 내용 변경 없이 이동.

예제 JSONL의 `../evaluation_audio/`는 이동 후에도 프로젝트 루트의 같은 녹음 폴더를 가리킵니다. 빈 examples 폴더와 생성 캐시만 있던 tools 폴더는 제거했습니다. 모델·환경·녹음·프로필·캐시·로그 및 Arduino 폴더는 원래 위치를 유지합니다. tools 안의 삭제 대상은 경로와 파일 유형을 검사한 Python 생성 캐시뿐입니다.

## 유지하는 인터페이스와 정책

기본 전사, `--assist`, `--plan`, `--gesture`, 마이크 진단·녹음·STT 비교 및 텍스트 보조 진입점을 유지합니다. `process_command`, `CommandDecision`, `CommandResult`, `ActionPlan`, 공개 음성 함수의 기존 호출 경로도 유지합니다. 구형 TTS 옵션은 계속 복원 안내와 종료 코드 2로 거절합니다.

임시 전사는 명령으로 전달하지 않으며 긴 발화는 최종 품질 검사를 통과해야 한 번 전달합니다. 접수 당시 JPEG·명령 ID·FIFO·분류 후 API 호출·이미지 전송 범위·제한 시간·재시도 정책을 유지합니다. 종료는 입력 중단 → 최종 전사 완료 → 카메라 종료 → AI 명령 마무리 → API 클라이언트 종료 → 로그 종료 순서입니다.

## 검증

- 정리 전 기준선: 자동 테스트 101개 통과. 기존 테스트 이름 101개를 기록해 이동 후 누락 여부를 대조합니다.
- 소스 통합 후: 기존 테스트 101개 통과.
- 백업 162개 파일의 상대 목록과 파일별 SHA-256이 이동 전후 일치합니다.
- 백업 목록·해시 사전의 정렬 JSON SHA-256: `328c778468f7d5ba5e40a3c2d45fec63bd16d60aeda20741d1661936d77fcfc3`.
- TTS 보관 폴더 24개 파일 전체가 변경되지 않았습니다. 이 중 원본 소스·연결 지점 22개의 해시는 기존 manifest로도 검증합니다.
- 최종 전체 테스트 101개 통과. 정리 전 테스트 이름 101개와 대조해 누락이 없음을 확인했습니다.
- 이동한 함수·클래스 22개의 구문 구조를 비교해 내부 import 경로 외의 본문 변경이 없음을 확인했습니다.
- 문법 검사와 정적 참조 검사를 통과했으며, 활성 문서 링크 10개와 평가 예제의 녹음 상대 경로를 확인했습니다.
- 기본 설치와 기능별 설치 목록 5개의 패키지·버전·중첩 참조 결과가 정리 전과 동일합니다. 제거한 내부 모듈을 import하는 활성 코드와 테스트는 없습니다.

실제 마이크·카메라와 외부 API 품질은 별도 검증 대상입니다. 성능 개선이나 디스크 사용량 감소를 주장하지 않습니다. TTS 복원 절차는 [RESTORE.md](../archive/tts/RESTORE.md), 보관 자료 위치는 [보관 안내](../archive/README.md)를 참고하세요.
